# 漫游者的夜歌 · The Wanderer's Nocturne

卫心玥的首次 2D 到 3D 游戏探索与制作手记。

**[打开项目介绍网站](https://a-little-snack-123.github.io/wanderers-nocturne/)**

一个以月夜、提灯、云海与幻想学院为主题的项目。网站呈现体验定位、美术思考、AI 参考拆解、人物版本迭代、六个空间的对照，以及当前网页原型的实际录屏。

## 可以在网站里看什么

- 当前 v11 原型的 36 秒实机录屏：长桥行走、大厅、旋梯、窗边、回廊与坐读。
- 人物 v4、v6、v8 与当前场景中的比较，侧脸厚度修正案例。
- 六区参考与实机对照，窗边构图和灯光的迭代。
- 可筛选、放大到原尺寸的 AI 参考图库。
- 从草图与自然语言，到 Image、Codex、Blender 和网页检查的工作流程。

## 贡献与完成度

创作者负责体验定位、美术方向、参考选择、反馈与验收。Image 协助视觉探索，Codex 协助脚本、建模实现及网页接入。

游戏仍在制作中。参考图、Blender 渲染和网页实机以图注明确区分。视频通过游戏内观景点切换展示多个场景，不代表连续通关。没有加速或使用概念动画替代实际游戏。录制源为 800 × 450，裁去右侧录制空白后为 720 × 450、36.08 秒，提供 H.264 MP4 和 WebM。

这是独立的项目介绍仓库，不包含完整游戏制作源或大型 Blender/GLB 资产，也未合并到个人作品集。

## 本地预览

无构建步骤、无前端依赖。使用 Python：

```sh
python -m http.server 4180 --directory docs
```

打开 `http://localhost:4180`。GitHub Pages 发布源为 `main` 分支的 `/docs`。

## 结构

```text
docs/                 静态网站与选定的公开素材
docs/assets/manifest.json  图像来源、尺寸与类别
scripts/              媒体准备及浏览器验证脚本
AGENTS.md             维护约定
HANDOFF.md            交接说明
CHANGELOG.md          版本记录
```

项目图像仅用于记录本项目的设计与迭代；未授予第三方批量复用图像的许可。对参考游戏的讨论是创作者的分析，未将其角色、地图或截图用于本站素材。
