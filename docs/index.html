漫游者的夜歌

提一盏灯，走进月光。
我的第一次，从二维想象到三维世界。

观看实机漫游 ▷

我想做一个让人愿意
慢下来、四处看看的世界。

这是一次以慢节奏探索和轻解谜为方向的幻想游戏尝试。它从一间魔法书阁出发，逐渐长出云海、塔楼、长桥与阅读角。现在，我把重心放在角色、空间氛围和实际漫游体验上。

我负责体验定位、美术方向、参考选择和反馈验收，借助 Image 探索二维视觉，再通过 Codex 与 Blender 将想法转成可编辑资产和网页原型。

INSIDE THE WORLD

先在这个世界里，走一走。

长桥上的前进、大厅里的停留，以及窗边的远眺。

录屏包含真实键盘行走与视角操作。场景间通过游戏内观景点切换，不代表一次连续通关；运行流畅度与美术仍在优化。

下载实机录屏

先确定感受，再决定画面。

安静、温暖、好奇，是我用来判断每个设计选择的三个词。

小小的旅人，辽阔的空间

我关注《光遇》中角色与环境的尺度关系。把人物放进更大的建筑和云海里，让远处的塔楼成为想要走近的目标。

画面要有焦点，也要有呼吸

拆解《Ori》时，我关注角色与背景的明暗分离；观察《风之旅人》时，我关注地标、留白和探索情绪。这里记录的是我对作品的观察与转译。

神秘感，来自还没看见的地方

窗外的远城、转折的楼梯和回廊尽头的光，让一个小场景有继续延伸的感觉。过多装饰和平均照明，反而会削弱这种期待。

冷月光里，留一盏暖灯。

低饱和度控制整体气质，冷暖与明暗建立视觉层级。夜景需要看得清，低饱和也不等于一片灰。

蓝灰夜空与布料
月白石材与云层
暖金灯火与焦点
深木色室内与书桌

FINDING THE TRAVELER

一个小旅人，改了很多遍。

从轮廓到侧脸，从袖口到握灯。二维形象成立之后，还要让每个角度都说得通。

先找到轮廓，还没有找到质感。

蓝色外套、浅色头发、挎包和提灯，建立了角色的基本识别。但发片像整块壳面，袖口与手部的衔接也需要继续检查。

下一步：检查侧面厚度、发束层次，以及提灯的承重关系。

“侧脸脑袋太扁”，
是一条可以执行的反馈。

只看正面，头部似乎已经成立；转到侧面，颅骨、面颊与头发包覆的厚度问题才显露出来。我开始要求正、侧、背和四分之三视角一起检查。

反馈逐渐具体到体积与结构：补足头部前后厚度，区分刘海与后发层次，再检查发束是否贴合。后脑壳面感与衣料自然度仍在继续打磨。

同一个世界，六种停留。

参考图是视觉目标。实机截图记录当下的距离。选择一个场景，看看我在改什么。

我想要的体验

长桥把视线引向塔楼，暖灯沿路径递进；小旅人走在连续的云海之上。

这一轮在修改

调整圆顶、建筑退台与铺砖，建立主塔和远城的层次。

仍需解决

云团仍有独立块状感；远景雾化、石材细节与灯光层级还不够自然。

ONE ITERATION, UP CLOSE

窗里有塔，
还不等于“窗边远眺”。

早期近塔几乎填满窗洞，桌灯、人物和远景无法同时读清。于是先调整窗洞与塔的位置，给远城和月亮留出空间。

灯光也反复过：欠曝时细节消失，补光过强又像白天。接下来仍要在可读性和月夜感之间找到平衡。

判断顺序：构图 → 轮廓 → 比例 → 纵深 → 灯光 → 材质 → 细节。

把一张想象，拆成可讨论的细节。

WORKING WITH AI

我的工作，是让每一轮更接近目标。

草图表达布局，文字补充约束，图像帮助讨论，三维与实机暴露问题。

表达想法

手绘草图与自然语言描述，明确空间布局、角色轮廓、情绪和配色。

生成与选择参考

用 Image 探索方向，筛选整体效果，再补人物多视图和场景模块拆解。

转成三维资产

让 Codex 编写脚本、调用 Blender，生成与修改模型，保存可编辑源并导出 GLB。

回到实际体验

接入网页，行走、转身、靠近物体。用渲染与实机截图检查比例、碰撞、镜头和光线。

把差异写具体

从“不够精致”走向“侧脸太扁、窗框缺失、提灯穿袖、灯下过曝”，安排下一轮修改。

一条反馈，如何变成制作任务

“画面明显太暗了。”

这条实际反馈要求重新检查曝光与照明。制作记录中发现，室内反弹光不足，灯具内部的光还被灯罩遮挡。

明确修改对象

分别检查窗外冷光、桌灯暖光和室内补光，让衣服、木材与纸页重新可读。

避免引入另一个问题

第一轮补光后画面偏灰白，失去了月夜感。继续收回正面补光，保留局部暖色焦点和有细节的暗部。

规定如何验收

保留同机位前后渲染；再到网页里检查实际效果。运行成功、模型导出成功，都不能代替视觉验收。

世界已经展开，
细节还在生长。

这次尝试让我理解：二维画面成立，只是三维体验的开始。

已经走到这里

人物与建筑有可编辑的 Blender 源文件，网页原型支持第一、第三人称漫游，并包含移动、楼梯与阅读交互。多轮参考、渲染、截图和反馈记录构成了迭代依据。

我的贡献与 AI 分工

我主导体验定位、视觉方向、参考选择、优先级与验收。Image 协助探索视觉，Codex 协助脚本、建模实现与网页接入。这是一次真实的学习和协作过程。

接下来要打磨

  • 空间云海的连续感、近中远景关系与建筑比例。
  • 人物发束与衣料、握灯接触、行走和坐读的自然度。
  • 体验窄处镜头、网页性能，以及视觉与交互的一致性。
  • 沉淀整理可复用的风格参考、任务描述和验收方法。
