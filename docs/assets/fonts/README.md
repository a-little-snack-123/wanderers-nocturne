# Brush heading font

Current heading font: Ma Shan Zheng (马善政毛笔楷体), The Ma Shan Zheng Project Authors.

- Source: https://github.com/google/fonts/tree/main/ofl/mashanzheng
- Upstream: https://github.com/googlefonts/mashanzheng
- License: SIL Open Font License 1.1, included as OFL-MaShanZheng.txt.
- Original TTF is preserved. nocturne-brush.woff2 is a web subset covering the current static and interactive site text, generated with scripts/subset_font.py. Regenerate after adding new Chinese headings.
- The earlier Zhi Mang Xing source and its license are retained for the typography iteration record; it is no longer loaded by the page.

The creator requested clearer brush lettering after reviewing Zhi Mang Xing. Ma Shan Zheng uses more complete, upright brush strokes. Small size and baseline variations on headings create rhythm while preserving selectable text. Body text uses system sans-serif fonts. This approximates the reference's calligraphic direction; it is not an identification of its exact lettering.
