# Brush heading font

Zhi Mang Xing (钟齐志莽行书), Wei Zhimang / The Zhi Mang Xing Project Authors.

- Source: https://github.com/google/fonts/tree/main/ofl/zhimangxing
- Upstream: https://github.com/googlefonts/zhimangxing
- License: SIL Open Font License 1.1, included as OFL-ZhiMangXing.txt.
- Original TTF is preserved. nocturne-brush.woff2 is a web subset covering the current static and interactive site text, generated with scripts/subset_font.py. Regenerate after adding new Chinese headings.

Used for display headings, following the creator's brush-calligraphy reference. Body text uses system sans-serif fonts to remain readable. This approximates the reference's calligraphic direction; it is not an identification of the exact lettering in that image.
